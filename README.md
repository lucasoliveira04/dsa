# DSA e desafios de programação

Repositório de estudos sobre estruturas de dados, algoritmos e resolução de desafios de programação em diferentes linguagens.

As soluções foram reunidas a partir dos meus estudos no LeetCode e no Beecrowd. O objetivo é manter um histórico organizado de aprendizado, facilitar revisões e acompanhar minha evolução na resolução de problemas.

## Linguagens

- Java
- C++
- Python
- SQL

## Organização

```text
src/main/
├── cpp/
│   ├── challanges_beecrowd/
│   └── challanges_leetcode/
├── java/org/dsa/
│   ├── challanges_beecrowd/
│   ├── challanges_leetcode/
│   └── patterns/
├── python/
│   ├── challanges_beecrowd/
│   └── challanges_leetcode/
└── sql/
    ├── challanges_beecrowd/
    └── challanges_leetcode/
```

Cada plataforma está separada por linguagem. As soluções do LeetCode também podem estar agrupadas por técnica ou categoria, como hash tables, strings e two pointers.
